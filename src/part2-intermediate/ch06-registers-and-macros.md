# Chapter 6: 레지스터와 매크로

Chapter 3에서 `d`, `y`, `p`를 배울 때 "레지스터에 저장된다"는 말을 했다. 이 챕터에서는 그 레지스터 체계를 깊이 이해하고, 레지스터를 기반으로 작동하는 매크로(macro)까지 마스터한다.

레지스터를 이해하면 클립보드를 여러 개 가진 것과 같은 효과를 얻고, 매크로를 익히면 반복 작업을 완전 자동화할 수 있다.

## 레지스터 체계

Vim의 레지스터는 텍스트를 저장하는 **이름 붙은 저장소**다. 삭제, 복사, 매크로 녹화 등 다양한 상황에서 사용된다.

### 기본 레지스터 (Unnamed Register): `""`

아무 레지스터도 지정하지 않고 `d`, `c`, `y`, `p`를 사용하면 **기본 레지스터** `""`가 사용된다.

```
dd      → "" 레지스터에 삭제된 줄이 저장됨
yiw     → "" 레지스터에 단어가 복사됨
p       → "" 레지스터의 내용을 붙여넣기
```

기본 레지스터는 마지막으로 삭제하거나 복사한 텍스트를 항상 담고 있다.

### 번호 레지스터 (Numbered Registers): `"0` ~ `"9`

| 레지스터 | 내용 |
|----------|------|
| `"0` | 마지막으로 **복사(yank)**한 텍스트 |
| `"1` | 마지막으로 **삭제(delete/change)**한 텍스트 (한 줄 이상) |
| `"2` ~ `"9` | 이전 삭제 내역 (큐처럼 밀려남) |

`"0`은 매우 유용하다. 다음 상황을 보자:

```
1. yiw     → "hello"를 복사 → "0에 저장
2. dw      → 다른 단어를 삭제 → "" 레지스터가 삭제된 단어로 덮어씌워짐
3. p       → 삭제된 단어가 붙여넣어짐 (원하지 않는 결과!)
4. "0p     → 처음 복사한 "hello"가 붙여넣어짐 (원하는 결과!)
```

> **핵심**: `yy`로 복사 후 다른 곳에서 `dd`로 삭제하고 `p`하면 삭제한 내용이 붙는다. **`"0p`**를 사용하면 복사한 내용을 붙여넣을 수 있다.

### 명명 레지스터 (Named Registers): `"a` ~ `"z`

26개의 알파벳 레지스터를 직접 지정하여 사용할 수 있다. 텍스트를 의도적으로 특정 레지스터에 저장하고 꺼내 쓸 때 사용한다.

**저장 (소문자: 덮어쓰기)**:

```
"ayiw    → a 레지스터에 현재 단어 복사
"bdd     → b 레지스터에 현재 줄 삭제(잘라내기)
"cyi"    → c 레지스터에 따옴표 안의 내용 복사
```

**추가 (대문자: 기존 내용에 이어붙이기)**:

```
"Ayy     → a 레지스터에 현재 줄을 이어붙이기
"Bdd     → b 레지스터에 현재 줄을 이어붙이기
```

대문자를 사용하면 기존 내용을 지우지 않고 뒤에 추가한다. 여러 곳에서 텍스트를 모아 한 번에 붙여넣을 때 유용하다.

**붙여넣기**:

```
"ap      → a 레지스터의 내용을 커서 뒤에 붙여넣기
"bP      → b 레지스터의 내용을 커서 앞에 붙여넣기
```

### 시스템 클립보드: `"+` 와 `"*`

Vim의 레지스터는 기본적으로 시스템 클립보드와 분리되어 있다. 외부 프로그램과 텍스트를 주고받으려면 시스템 클립보드 레지스터를 사용해야 한다.

| 레지스터 | 설명 |
|----------|------|
| `"+` | 시스템 클립보드 (clipboard) |
| `"*` | 선택 클립보드 (X11의 primary selection, macOS에서는 `"+`와 동일) |

```
"+yiw    → 현재 단어를 시스템 클립보드에 복사
"+y$     → 줄 끝까지 시스템 클립보드에 복사
"+yy     → 현재 줄을 시스템 클립보드에 복사
"+p      → 시스템 클립보드에서 붙여넣기
```

> **팁**: 매번 `"+y`, `"+p`를 치기 번거롭다면, `init.lua`에서 다음과 같이 설정할 수 있다:
> ```lua
> vim.opt.clipboard = "unnamedplus"
> ```
> 이렇게 하면 모든 `y`, `d`, `p`가 시스템 클립보드와 연동된다. 편리하지만 레지스터 분리의 이점을 잃으므로, 취향에 따라 선택한다.

### 읽기전용 레지스터

직접 값을 저장할 수 없고, Vim이 자동으로 관리하는 레지스터들이다.

| 레지스터 | 내용 |
|----------|------|
| `"%` | 현재 파일 이름 |
| `"#` | 이전 파일 이름 (alternate file) |
| `":` | 마지막으로 실행한 Command-line 명령 |
| `".` | 마지막으로 Insert 모드에서 입력한 텍스트 |

```
"%p      → 현재 파일 이름을 붙여넣기
":p      → 마지막 명령을 붙여넣기 (예: :%s/old/new/g)
".p      → 마지막 입력 텍스트를 붙여넣기
```

### 블랙홀 레지스터: `"_`

`"_`에 보내면 텍스트가 완전히 사라진다. 어떤 레지스터도 덮어쓰지 않는다.

```
"_dd     → 현재 줄 삭제, 어떤 레지스터에도 저장하지 않음
"_diw    → 현재 단어 삭제, 레지스터 보존
```

**활용 시나리오**: 텍스트를 복사한 뒤, 다른 텍스트를 삭제하고 복사한 내용을 붙여넣고 싶을 때:

```
1. yiw          → 단어 복사 ("0에 저장)
2. "_diw        → 다른 단어 삭제 (블랙홀로 → 레지스터 보존)
3. P            → 복사한 단어 붙여넣기
```

`"_`를 쓰지 않으면 2번에서 기본 레지스터가 덮어씌워져서 `p`로 원하는 내용을 붙여넣을 수 없다.

### 표현식 레지스터: `"=`

Insert 모드나 Command-line 모드에서 `<C-r>=`로 접근한다. Vim 표현식을 평가한 결과를 삽입할 수 있다.

```
Insert 모드에서:
<C-r>=2+3<CR>        → "5"가 삽입됨
<C-r>=system("date")<CR>  → 현재 날짜가 삽입됨
```

계산 결과나 변수 값을 빠르게 삽입할 때 유용하다.

## 레지스터 확인하기

### :registers (:reg)

현재 모든 레지스터의 내용을 확인할 수 있다.

```vim
:registers          " 모든 레지스터 확인
:reg                " 축약형
:reg abc            " a, b, c 레지스터만 확인
:reg 0              " 0번 레지스터만 확인
```

출력 예시:

```
--- Registers ---
""   hello world
"0   hello world
"1   deleted line
"a   my saved text
"+   clipboard content
```

레지스터 내용을 수시로 확인하는 습관을 들이면, 예상치 못한 붙여넣기 결과를 피할 수 있다.

## 매크로 (Macros)

매크로는 일련의 키 입력을 녹화하고 재생하는 기능이다. 매크로는 **레지스터에 저장**되므로, 레지스터 체계를 이해해야 매크로를 제대로 활용할 수 있다.

### 매크로 기본 사용법

```
q{register}     매크로 녹화 시작 (하단에 "recording @a" 표시)
  ...           키 입력 (일반적인 편집 동작)
q               매크로 녹화 종료

@{register}     매크로 실행
@@              마지막으로 실행한 매크로 반복
{count}@{register}  매크로를 count번 반복 실행
```

### 첫 번째 매크로 만들기

다음과 같은 목록이 있다고 하자:

```
apple
banana
cherry
date
elderberry
```

각 줄을 `- [ ] apple` 형태의 체크리스트로 변환하고 싶다:

1. 첫 번째 줄에 커서를 놓는다
2. `qa` → a 레지스터에 매크로 녹화 시작
3. `I- [ ] ` → 줄 앞에 `- [ ] ` 삽입 → `<Esc>`
4. `j` → 다음 줄로 이동
5. `q` → 녹화 종료

이제 `4@a`로 나머지 4줄에 한 번에 적용한다.

결과:

```
- [ ] apple
- [ ] banana
- [ ] cherry
- [ ] date
- [ ] elderberry
```

### 좋은 매크로를 만드는 원칙

매크로를 작성할 때는 반복 실행에 안전하도록 설계해야 한다:

1. **줄의 시작이나 끝에서 시작하라**: `0` 또는 `^`로 줄 시작으로 이동한 뒤 작업을 시작
2. **검색 기반 이동을 활용하라**: `f`, `t`, `/` 등으로 정확한 위치를 찾아 이동
3. **다음 대상으로 이동하는 동작을 포함하라**: `j`, `n` 등으로 다음 작업 대상으로 이동하는 것으로 마무리
4. **상대적인 모션을 사용하라**: 특정 열 번호에 의존하지 말고, `w`, `f`, `/` 등을 사용

## 매크로 실전 패턴

### 패턴 1: CSV를 JSON으로 변환

입력:

```
name,age,city
Alice,30,Seoul
Bob,25,Busan
```

데이터 행을 JSON 객체로 변환하는 매크로:

1. 두 번째 줄(Alice)에 커서를 놓는다
2. `qa` → 녹화 시작
3. `0` → 줄 시작으로
4. `i{ "name": "` → 앞부분 삽입 → `<Esc>`
5. `f,` → 첫 번째 쉼표로 이동
6. `s", "age": ` → 쉼표를 교체 → `<Esc>`
7. `f,` → 두 번째 쉼표로 이동
8. `s, "city": "` → 쉼표를 교체 → `<Esc>`
9. `A" },` → 줄 끝에 추가 → `<Esc>`
10. `j` → 다음 줄로
11. `q` → 녹화 종료

`@a`로 다음 줄에 적용한다.

### 패턴 2: 연번 추가

```
Item
Item
Item
Item
```

각 줄에 번호를 붙이고 싶다 (`1. Item`, `2. Item`, ...):

이 경우 표현식 레지스터와 변수를 활용한다:

```vim
:let i = 1
qa
0
I<C-r>=i<CR>. <Esc>
:let i += 1
j
q
```

`3@a`로 나머지 줄에 적용한다.

### 패턴 3: 특정 패턴이 있는 줄만 편집

로그 파일에서 `ERROR`가 포함된 줄의 앞에 `>>> `를 추가하고 싶다:

```
INFO: Server started
ERROR: Connection failed
INFO: Request received
ERROR: Timeout occurred
INFO: Processing complete
```

```
qa
/ERROR<CR>
I>>> <Esc>
q
```

`@a`를 반복하거나, `100@a`처럼 큰 수를 지정하면 해당 패턴이 없을 때 자동으로 멈춘다.

## 재귀 매크로

매크로가 자기 자신을 호출하게 만들면, 파일 끝이나 오류가 날 때까지 자동으로 반복된다.

### 재귀 매크로 패턴

```
qaq         → a 레지스터를 비움 (빈 매크로 녹화 즉시 종료)
qa          → a 레지스터에 녹화 시작
  ...       → 편집 동작
  @a        → 자기 자신을 호출 (재귀)
q           → 녹화 종료
@a          → 실행!
```

**왜 `qaq`로 먼저 비우는가?**

녹화 도중 `@a`를 실행하면, 그 시점의 a 레지스터 내용이 실행된다. 이전에 다른 매크로가 a에 저장되어 있으면 예상치 못한 동작이 발생할 수 있다. `qaq`로 비워두면 녹화 중 `@a`는 아무것도 하지 않고, 녹화가 끝난 후에야 완성된 매크로가 재귀적으로 동작한다.

### 재귀 매크로 예시

모든 줄 끝에 세미콜론을 추가하는 재귀 매크로:

```
qaq             → a 레지스터 비우기
qa              → 녹화 시작
A;<Esc>         → 줄 끝에 ; 추가
j               → 다음 줄로 이동
@a              → 자기 자신 호출
q               → 녹화 종료
@a              → 실행 (파일 끝까지 자동 반복)
```

파일 끝에 도달하면 `j`가 실패하여 매크로가 자동으로 멈춘다.

> **주의**: 재귀 매크로는 강력하지만, 실수하면 의도치 않은 대량 편집이 발생할 수 있다. 실행 전에 `u`로 되돌릴 수 있음을 기억하자.

## 매크로 편집

매크로는 레지스터에 저장된 키 입력 시퀀스이므로, 일반 텍스트처럼 편집할 수 있다.

### 매크로 내용 확인

```vim
:reg a              " a 레지스터 내용 확인
```

### 매크로 붙여넣기 → 편집 → 다시 저장

매크로를 수정하고 싶을 때:

1. **빈 줄에 매크로 붙여넣기**:

```
"ap         → a 레지스터의 매크로 내용을 붙여넣기
```

붙여넣은 내용은 키 입력의 텍스트 표현이다. 예를 들어:

```
I- [ ] ^[j
```

여기서 `^[`는 `<Esc>` 키를 나타낸다.

2. **텍스트를 편집**:

일반 편집 명령으로 내용을 수정한다. 예를 들어 `- [ ] `를 `- [x] `로 변경:

```
I- [x] ^[j
```

3. **다시 레지스터에 저장**:

```
0"ay$       → 줄 시작부터 끝까지를 a 레지스터에 복사
```

또는 해당 줄에서 `"ayy`로 줄 전체를 복사한다 (단, 줄바꿈이 포함됨에 주의).

4. **편집한 줄 삭제**:

```
dd          → 임시로 붙여넣었던 줄 삭제
```

### 매크로에 추가하기

기존 매크로에 동작을 추가하고 싶으면, 대문자 레지스터로 이어서 녹화한다:

```
qA          → a 레지스터에 이어서 녹화 (기존 내용 뒤에 추가)
  ...       → 추가할 동작
q           → 녹화 종료
```

4. `"+yy`로 한 줄을 시스템 클립보드에 복사 → 다른 프로그램에 붙여넣기
5. `:reg`로 레지스터 상태 확인

```
apple
banana
cherry
date
elderberry
fig
grape
```

연습 과제:

1. 각 줄을 `<li>apple</li>` 형태의 HTML 리스트 아이템으로 변환하는 매크로를 만들어라
   - 힌트: `qa` → `I<li>` → `<Esc>` → `A</li>` → `<Esc>` → `j` → `q`

### 실습 3: 재귀 매크로

다음 코드의 모든 `var`를 `const`로 변경하는 재귀 매크로를 만들어라:

```javascript
var a = 1;
var b = 2;
var c = 3;
var d = 4;
var e = 5;
var f = 6;
var g = 7;
var h = 8;
```

힌트:

```
qaq                 → a 레지스터 비우기
qa                  → 녹화 시작
0                   → 줄 시작으로
cw                  → 단어 변경
const               → "const" 입력
<Esc>               → Normal 모드로
j                   → 다음 줄로
@a                  → 재귀 호출
q                   → 녹화 종료
@a                  → 실행
```

## 핵심 정리

- Vim에는 **다양한 종류의 레지스터**가 있다: 기본(`""`), 번호(`"0`~`"9`), 명명(`"a`~`"z`), 클립보드(`"+`, `"*`), 읽기전용(`"%`, `"#`, `":`, `".`), 블랙홀(`"_`), 표현식(`"=`)
- **`"0`**에는 마지막 yank 내용이 보존된다 -- 삭제 후에도 `"0p`로 복사한 내용을 붙여넣을 수 있다
- **`"_`** (블랙홀)로 삭제하면 다른 레지스터를 덮어쓰지 않는다
- **`"+y`**, **`"+p`**로 시스템 클립보드와 연동한다
- **매크로**: `q{reg}`로 녹화, `@{reg}`로 실행, `@@`로 반복
- **재귀 매크로**: `qaq` → `qa...@aq` 패턴으로 파일 끝까지 자동 반복
- 매크로는 레지스터에 저장되므로 **`"ap`로 붙여넣어 편집** 가능
- 좋은 매크로는 **위치에 독립적인 모션**을 사용하고, **다음 대상으로 이동하는 동작**으로 끝난다
