# Chapter 5: 텍스트 오브젝트

텍스트 오브젝트(text object)는 Vim 편집 언어에서 가장 세련된 "명사"다. 모션이 "커서부터 어디까지"를 지정한다면, 텍스트 오브젝트는 **커서 주변의 구조화된 텍스트 단위**를 지정한다.

텍스트 오브젝트를 알면 커서를 정확한 위치에 놓을 필요가 없다. 대상 안에만 있으면 된다.

## inner vs around

텍스트 오브젝트는 두 종류로 나뉜다:

- **`i`** (inner): 대상의 **안쪽 내용만**
- **`a`** (a/around): 대상 **포함 주변 공백/구분자까지**

```
"Hello World"
 ←  inner  →     ci" → 따옴표 안의 내용만 변경
←   around   →   da" → 따옴표까지 포함하여 삭제
```

## 기본 텍스트 오브젝트

### 단어 (word)

| 오브젝트 | 범위 |
|----------|------|
| `iw` | 현재 단어 |
| `aw` | 현재 단어 + 주변 공백 |
| `iW` | 현재 WORD |
| `aW` | 현재 WORD + 주변 공백 |

```
Hello, beautiful world!
       ↑ 커서 위치

diw → "Hello,  world!"         (beautiful만 삭제)
daw → "Hello, world!"          (beautiful + 앞 공백 삭제)
```

`diw`와 `daw`의 차이: `daw`는 주변 공백까지 삭제하므로 단어를 제거한 뒤 공백이 중복되지 않는다.

### 문장 (sentence)

| 오브젝트 | 범위 |
|----------|------|
| `is` | 현재 문장 |
| `as` | 현재 문장 + 뒤 공백 |

Vim에서 문장은 `.`, `!`, `?` 뒤에 공백이나 줄바꿈이 오는 것으로 구분된다.

### 단락 (paragraph)

| 오브젝트 | 범위 |
|----------|------|
| `ip` | 현재 단락 (빈 줄로 구분) |
| `ap` | 현재 단락 + 뒤의 빈 줄 |

코드에서 단락은 빈 줄로 구분된 블록이다. 함수 하나를 통째로 선택하거나 복사할 때 유용하다.

## 괄호와 따옴표

프로그래밍에서 가장 많이 사용하는 텍스트 오브젝트다.

### 괄호류

| 오브젝트 | 범위 | 별칭 |
|----------|------|------|
| `i(` 또는 `i)` | `()` 안의 내용 | `ib` |
| `a(` 또는 `a)` | `()` 포함 | `ab` |
| `i{` 또는 `i}` | `{}` 안의 내용 | `iB` |
| `a{` 또는 `a}` | `{}` 포함 | `aB` |
| `i[` 또는 `i]` | `[]` 안의 내용 | |
| `a[` 또는 `a]` | `[]` 포함 | |
| `i<` 또는 `i>` | `<>` 안의 내용 | |
| `a<` 또는 `a>` | `<>` 포함 | |

### 따옴표류

| 오브젝트 | 범위 |
|----------|------|
| `i"` | 큰따옴표 안의 내용 |
| `a"` | 큰따옴표 포함 |
| `i'` | 작은따옴표 안의 내용 |
| `a'` | 작은따옴표 포함 |
| `` i` `` | 백틱 안의 내용 |
| `` a` `` | 백틱 포함 |

### 태그 (HTML/XML)

| 오브젝트 | 범위 |
|----------|------|
| `it` | 태그 안의 내용 |
| `at` | 태그 포함 |

```html
<div class="container">Hello World</div>
```

- `cit` → 태그 안의 "Hello World"를 변경
- `dat` → `<div>` 태그 전체를 삭제

## 실전 조합표

가장 자주 사용하는 텍스트 오브젝트 + 오퍼레이터 조합:

### 변경 (change) 조합

| 명령 | 의미 | 사용 장면 |
|------|------|-----------|
| `ciw` | 단어 변경 | 변수명, 함수명 변경 |
| `ci"` | 따옴표 안 변경 | 문자열 내용 변경 |
| `ci'` | 작은따옴표 안 변경 | 문자열 내용 변경 |
| `ci(` | 괄호 안 변경 | 함수 인자 변경 |
| `ci{` | 중괄호 안 변경 | 블록 내용 변경 |
| `ci[` | 대괄호 안 변경 | 배열 내용 변경 |
| `cit` | 태그 안 변경 | HTML 텍스트 변경 |
| `cis` | 문장 변경 | 문장 재작성 |
| `cip` | 단락 변경 | 단락 재작성 |

### 삭제 (delete) 조합

| 명령 | 의미 | 사용 장면 |
|------|------|-----------|
| `diw` | 단어 삭제 | 코드에서 이름만 제거 |
| `daw` | 단어 + 공백 삭제 | 단어를 깔끔하게 제거 |
| `da"` | 따옴표 포함 삭제 | 문자열 전체 제거 |
| `di{` | 중괄호 안 삭제 | 함수 본문 비우기 |
| `dap` | 단락 삭제 | 코드 블록 제거 |
| `dat` | 태그 포함 삭제 | HTML 요소 제거 |

### 복사 (yank) 조합

| 명령 | 의미 |
|------|------|
| `yiw` | 단어 복사 |
| `yi"` | 따옴표 안 복사 |
| `yap` | 단락 복사 |
| `yi{` | 중괄호 안 복사 |

### 선택 (visual) 조합

| 명령 | 의미 |
|------|------|
| `viw` | 단어 선택 |
| `vi"` | 따옴표 안 선택 |
| `vip` | 단락 선택 |
| `vi{` | 중괄호 안 선택 |
| `vat` | 태그 포함 선택 |

## 커서 위치의 유연성

텍스트 오브젝트의 큰 장점은 **커서가 대상 안 어디에 있든 동작한다**는 것이다.

```javascript
const message = "Hello, World!";
                       ↑ 커서가 여기에 있어도
```

`ci"` → 커서가 `W` 위에 있지만, 따옴표 안의 전체 내용 `Hello, World!`가 변경된다.

모션으로 같은 작업을 하려면:
1. `F"` → 여는 따옴표로 이동
2. `l` → 한 칸 오른쪽
3. `ct"` → 닫는 따옴표 전까지 변경

텍스트 오브젝트를 사용하면 **한 번에** 끝난다.

## 중첩된 구조에서의 동작

```javascript
if (isValid(user.getName())) {
    // 코드
}
```

커서가 `user` 위에 있을 때:
- `ci(` → 가장 가까운 `()`의 내용을 변경 → `getName`의 괄호 안
- `2ci(` 또는 바깥 괄호를 대상으로 → `isValid`의 괄호 안

중첩 수준이 깊으면 `%`로 괄호를 오가며 확인한 뒤 작업하는 것이 안전하다.

## 텍스트 오브젝트 확장 (플러그인 미리보기)

Neovim의 내장 텍스트 오브젝트 외에도, 플러그인으로 확장할 수 있다. Part 4에서 다룰 Treesitter 기반 텍스트 오브젝트는 다음과 같은 것을 가능하게 한다:

- `if` → 함수 안쪽 (inner function)
- `af` → 함수 전체 (a function)
- `ic` → 클래스 안쪽
- `ac` → 클래스 전체
- `ia` → 인자 하나
- `aa` → 인자 + 구분자

지금은 내장 텍스트 오브젝트에 집중하자.

## 실습: 텍스트 오브젝트 연습

다음 코드를 파일로 만들고 연습해 보자:

```html
<div class="container">
  <h1>Welcome to "My Site"</h1>
  <p>This is a paragraph with <strong>bold text</strong> inside.</p>
  <ul>
    <li>Item one</li>
    <li>Item two</li>
    <li>Item three</li>
  </ul>
</div>
```

```javascript
function processUser(user) {
  const fullName = user.firstName + " " + user.lastName;
  const email = user.getEmail("primary");
  if (user.isActive && user.hasPermission("admin")) {
    return { name: fullName, email: email, role: "admin" };
  }
  return null;
}
```

연습 과제:
1. `"My Site"`를 `"Our Site"`로 변경 → `ci"`
2. `<strong>bold text</strong>` 안의 텍스트 변경 → `cit`
3. `<li>Item two</li>` 전체 삭제 → `dat`
4. `processUser`의 인자 `user`를 `data`로 변경 → `ci(`
5. `"primary"` 삭제 (따옴표 포함) → `da"`
6. `if` 블록의 중괄호 안 내용 삭제 → `di{`
7. `{ name: fullName, email: email, role: "admin" }` 안의 내용 복사 → `yi{`
8. `"admin"` 문자열을 `"user"`로 변경 → `ci"`, 그리고 다른 `"admin"`도 `n.`으로 반복

## 핵심 정리

- 텍스트 오브젝트는 **커서 주변의 구조화된 텍스트 단위**를 지정한다
- **`i`** (inner): 안쪽 내용만 / **`a`** (around): 구분자 포함
- 프로그래밍에서 가장 많이 쓰는 것: **`ci"`**, **`ci(`**, **`di{`**, **`diw`**
- 커서가 대상 **안 어디에 있든** 동작한다 — 정확한 위치 불필요
- 오퍼레이터(d, c, y, v)와 자유롭게 조합: `{operator}{i/a}{object}`
- **`.`** (dot command)와 결합하면 반복 편집이 극도로 효율적
- 나중에 Treesitter 텍스트 오브젝트로 함수, 클래스 단위까지 확장 가능
