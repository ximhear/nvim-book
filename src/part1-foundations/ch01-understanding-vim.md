# Chapter 1: Vim의 철학 이해하기

Vim을 처음 접하면 "왜 이렇게 불편한 편집기를 쓰는 거지?"라는 의문이 든다. 화살표 키 대신 `h`, `j`, `k`, `l`을 쓰고, 텍스트를 입력하려면 먼저 `i`를 눌러야 하고, 종료하는 것조차 `:q`를 알아야 한다.

하지만 이 모든 "불편함"에는 이유가 있다. Vim은 **텍스트 편집을 위한 언어**를 제공한다. 이 언어를 이해하면, 머릿속으로 생각한 편집 작업을 거의 즉시 실행할 수 있다.

## 모달 편집(Modal Editing)이란 무엇인가

대부분의 편집기는 키를 누르면 바로 텍스트가 입력된다. Vim은 다르다. 키의 동작이 **현재 모드**에 따라 달라진다. 이것을 모달 편집이라 한다.

왜 모달 편집인가? 키보드에는 키가 약 50개밖에 없다. 하나의 모드에서 이 키들은 "문자 입력"에만 쓰인다. 하지만 모드를 나누면, 같은 키를 "이동", "삭제", "복사" 등 전혀 다른 용도로 활용할 수 있다. 50개의 키로 수백 가지 동작을 수행할 수 있는 이유다.

## 네 가지 핵심 모드

### Normal 모드

Neovim을 처음 열면 Normal 모드다. 이름 그대로, 이것이 **기본** 모드다.

Normal 모드에서는 텍스트를 입력하지 않는다. 대신:
- 커서를 이동하고
- 텍스트를 삭제, 복사, 붙여넣기하고
- 명령을 조합한다

```
코드를 "읽는 시간"이 "쓰는 시간"보다 훨씬 길다.
따라서 기본 모드가 "읽기/편집"인 것은 합리적이다.
```

다른 모드에서 Normal 모드로 돌아오려면 `<Esc>`를 누른다.

> **팁**: `<Esc>` 대신 `jk`나 `jj`를 매핑하는 사람도 많다. 또는 `<C-[>`도 Escape와 동일하게 동작한다. Caps Lock을 Escape로 매핑하는 것도 인기 있는 선택이다.

### Insert 모드

텍스트를 입력하는 모드다. 일반적인 편집기와 동일하게 동작한다.

Insert 모드로 진입하는 방법은 여러 가지다:

| 키 | 동작 |
|----|------|
| `i` | 커서 **앞**에서 입력 시작 |
| `a` | 커서 **뒤**에서 입력 시작 |
| `I` | 줄의 **첫 번째 비공백 문자** 앞에서 입력 |
| `A` | 줄의 **끝**에서 입력 |
| `o` | 현재 줄 **아래**에 새 줄 추가 후 입력 |
| `O` | 현재 줄 **위**에 새 줄 추가 후 입력 |
| `s` | 현재 문자를 **삭제**하고 입력 |
| `S` | 현재 줄을 **삭제**하고 입력 |

이 중 가장 많이 쓰는 것은 `i`, `a`, `o`, `A`다. 상황에 맞는 진입 방법을 선택하면 불필요한 커서 이동을 줄일 수 있다.

### Visual 모드

텍스트를 시각적으로 선택하는 모드다. 마우스로 드래그하여 선택하는 것과 비슷하지만, 키보드로 정밀하게 조작할 수 있다.

| 키 | 동작 |
|----|------|
| `v` | 문자 단위 선택 |
| `V` | 줄 단위 선택 |
| `<C-v>` | 블록(사각형) 선택 |

Visual 모드는 Chapter 4에서 자세히 다룬다.

### Command-line 모드

`:`를 누르면 화면 하단에 명령줄이 나타난다. 여기서 Ex 명령을 입력한다:

```vim
:w          " 저장
:q          " 종료
:wq         " 저장 후 종료
:q!         " 저장하지 않고 강제 종료
:%s/foo/bar/g  " 전체 텍스트에서 foo를 bar로 치환
```

Command-line 모드는 Chapter 9에서 깊이 다룬다.

## 모드 전환 흐름

```
                 i, a, o, ...
    ┌──────────────────────────────┐
    │                              ▼
 Normal ◄──── Esc ──── Insert
    │  ▲
    │  │
    │  Esc
    │  │
    ▼  │
 Visual ─────────────────────────►
    │
    │  :
    ▼
 Command-line ──── Esc ──► Normal
```

핵심 원칙: **작업이 끝나면 항상 Normal 모드로 돌아온다.**

## Vim의 편집 언어: 동사 + 명사

Vim의 가장 강력한 개념은 편집 명령이 **언어처럼 조합**된다는 것이다.

### 동사 (Operator)

동작을 수행하는 명령:

| 동사 | 의미 |
|------|------|
| `d` | 삭제 (delete) |
| `c` | 변경 (change) - 삭제 후 Insert 모드 진입 |
| `y` | 복사 (yank) |
| `>` | 들여쓰기 (indent) |
| `<` | 내어쓰기 (outdent) |
| `=` | 자동 정렬 (auto-indent) |
| `gU` | 대문자로 (uppercase) |
| `gu` | 소문자로 (lowercase) |

### 명사 (Motion / Text Object)

동작의 범위를 지정하는 대상:

| 명사 | 의미 |
|------|------|
| `w` | 단어 (word) |
| `b` | 이전 단어 (back) |
| `$` | 줄 끝까지 |
| `0` | 줄 시작까지 |
| `G` | 파일 끝까지 |
| `gg` | 파일 시작까지 |
| `iw` | 단어 안쪽 (inner word) |
| `i"` | 따옴표 안쪽 |
| `ap` | 단락 전체 (a paragraph) |

### 조합의 힘

동사와 명사를 조합하면:

| 명령 | 의미 |
|------|------|
| `dw` | 단어 삭제 (delete word) |
| `d$` | 줄 끝까지 삭제 |
| `ci"` | 따옴표 안의 내용을 변경 (change inner ") |
| `yap` | 단락 전체 복사 (yank a paragraph) |
| `>G` | 현재 줄부터 파일 끝까지 들여쓰기 |
| `gUiw` | 현재 단어를 대문자로 |

새로운 동사를 하나 배우면, 이미 알고 있는 모든 명사와 조합할 수 있다. 새로운 명사를 하나 배우면, 이미 알고 있는 모든 동사와 조합할 수 있다. 이것이 Vim의 편집 언어가 강력한 이유다.

### 숫자와의 조합

동사 앞에 숫자를 붙이면 반복 횟수를 지정할 수 있다:

| 명령 | 의미 |
|------|------|
| `3dw` | 단어 3개 삭제 |
| `5j` | 아래로 5줄 이동 |
| `2yy` | 현재 줄 포함 2줄 복사 |
| `4>>` | 현재 줄부터 4줄 들여쓰기 |

문법을 정리하면:

```
[횟수] + 동사(operator) + [횟수] + 명사(motion)
```

## 왜 이 방식이 효율적인가

### 1. 조합 폭발 (Combinatorial Explosion)

10개의 동사와 20개의 명사를 배우면, 30개를 외운 것이 아니라 **200개의 명령**을 사용할 수 있다. 새로운 것을 하나 배울 때마다 활용 가능한 명령이 곱으로 증가한다.

### 2. 반복 가능성

`.` (dot) 명령은 마지막 편집 동작을 반복한다. `ciw`로 단어를 변경한 뒤, 다음 대상으로 이동해서 `.`만 누르면 같은 변경이 적용된다. 이 단순한 기능이 Vim 사용자의 생산성을 극적으로 높인다.

### 3. 손이 홈 로우를 떠나지 않는다

Vim의 모든 핵심 동작은 키보드의 홈 로우(home row) 근처에서 이루어진다. 화살표 키, 마우스, Home/End 키를 찾아 손을 움직일 필요가 없다.

## 실습: 첫 번째 편집 세션

터미널에서 Neovim을 열어보자:

```bash
nvim practice.txt
```

아래 내용을 따라 입력하고 편집해 보자:

1. `i`를 눌러 Insert 모드 진입
2. 다음 텍스트를 입력:
   ```
   Hello World
   This is my first Neovim session
   I am learning Vim's language
   ```
3. `<Esc>`를 눌러 Normal 모드로 복귀
4. `gg`로 파일 맨 위로 이동
5. `dw`로 "Hello" 삭제
6. `i`를 눌러 "Hi"를 입력하고 `<Esc>`
7. `j`로 아래 줄로 이동
8. `ci"`는 따옴표가 없으니 `cw`로 첫 단어 변경
9. `:wq`로 저장 후 종료

이것이 Vim의 기본적인 사용 흐름이다. 아직은 어색하겠지만 걱정하지 않아도 된다. 이어지는 챕터들에서 하나씩 깊이 파고들 것이다.

## 핵심 정리

- Vim은 **모달 편집기**다. 모드에 따라 같은 키가 다른 동작을 한다
- 네 가지 핵심 모드: **Normal**, **Insert**, **Visual**, **Command-line**
- 작업이 끝나면 항상 **Normal 모드로 돌아온다**
- Vim의 편집 명령은 **동사 + 명사**로 조합된다
- 동사 10개 + 명사 20개 = **200가지 명령** (외우는 것이 아니라 조합하는 것)
- `.` 명령으로 마지막 편집을 **반복**할 수 있다
