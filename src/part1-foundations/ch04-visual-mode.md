# Chapter 4: Visual 모드 마스터하기

Visual 모드는 편집할 텍스트 영역을 눈으로 확인하면서 선택할 수 있는 모드다. 마우스 드래그와 비슷하지만, Vim의 모든 모션과 결합할 수 있어 훨씬 강력하다.

일반적으로 Vim 숙련자들은 Visual 모드보다 오퍼레이터 + 모션 조합을 더 선호한다. 하지만 Visual 모드가 더 직관적인 상황들이 분명히 있으며, 특히 블록 선택은 다른 방법으로 대체하기 어렵다.

## 세 가지 Visual 모드

| 키 | 모드 | 설명 |
|----|------|------|
| `v` | Visual (문자 단위) | 문자 단위로 선택 |
| `V` | Visual Line (줄 단위) | 줄 단위로 선택 |
| `<C-v>` | Visual Block (블록) | 사각형 영역 선택 |

### Visual (v)

`v`를 누르면 현재 커서 위치부터 선택이 시작된다. 이동 명령으로 선택 범위를 확장한다:

```
이것은 [예시 텍스트]입니다.
```

`f[` → `v` → `f]` 이렇게 하면 `[예시 텍스트]`가 선택된다.

### Visual Line (V)

`V`를 누르면 줄 단위로 선택된다. 코드 블록을 통째로 선택할 때 유용하다:

```javascript
function hello() {     // V로 여기서 시작
  console.log("hi");   // j로 선택 확장
  return true;          // j로 선택 확장
}                       // 여기까지 선택됨
```

### Visual Block (<C-v>)

사각형 영역을 선택한다. 이것은 Visual 모드의 가장 독특하고 강력한 기능이다.

```
const a = 1;
const b = 2;
const c = 3;
const d = 4;
```

`<C-v>`로 블록 선택 모드에 진입하면, `j`/`k`로 위아래, `h`/`l`로 좌우로 사각형 범위를 조절할 수 있다.

## 선택 후 조작

Visual 모드에서 영역을 선택한 뒤, 다양한 명령을 적용할 수 있다:

### 기본 조작

| 키 | 동작 |
|----|------|
| `d` 또는 `x` | 선택 영역 삭제 |
| `c` | 선택 영역 삭제 후 Insert 모드 |
| `y` | 선택 영역 복사 |
| `p` | 선택 영역을 레지스터 내용으로 교체 |
| `r{char}` | 선택된 모든 문자를 `{char}`로 교체 |
| `~` | 대소문자 토글 |
| `U` | 대문자로 |
| `u` | 소문자로 |

### 들여쓰기

| 키 | 동작 |
|----|------|
| `>` | 선택 영역 들여쓰기 |
| `<` | 선택 영역 내어쓰기 |
| `=` | 자동 정렬 |

> **팁**: `>` 후에 선택이 해제되는데, `gv`로 마지막 선택을 다시 활성화한 뒤 `>`를 한 번 더 누를 수 있다. 또는 `.`으로 마지막 들여쓰기를 반복할 수도 있다.

### 줄 조합과 정렬

| 키 | 동작 |
|----|------|
| `J` | 선택된 줄들을 하나로 합침 |
| `:sort` | 선택된 줄들을 정렬 |

## 블록 선택의 실전 활용

### 여러 줄에 동시 입력

블록 선택의 가장 강력한 기능은 여러 줄에 동시에 텍스트를 삽입하는 것이다.

**예시: 여러 줄 앞에 주석 추가**

```python
line_one = 1
line_two = 2
line_three = 3
```

1. 첫 번째 줄의 맨 앞에 커서를 놓는다
2. `<C-v>` → `2j`로 3줄 선택
3. `I` → `# ` 입력 → `<Esc>`

결과:
```python
# line_one = 1
# line_two = 2
# line_three = 3
```

`I`는 블록 왼쪽에, `A`는 블록 오른쪽에 텍스트를 삽입한다.

> **주의**: `<Esc>`를 누른 직후에는 첫 번째 줄만 변경된 것처럼 보이지만, 잠시 후 모든 줄에 적용된다.

### 여러 줄 끝에 텍스트 추가

```javascript
var a = 1
var b = 2
var c = 3
```

줄 길이가 다를 때 각 줄 끝에 `;`를 추가하려면:

1. 첫 번째 줄에서 `<C-v>` → `2j` → `$`로 줄 끝까지 선택
2. `A` → `;` 입력 → `<Esc>`

결과:
```javascript
var a = 1;
var b = 2;
var c = 3;
```

`$`를 사용하면 줄 길이가 달라도 각 줄의 끝에 맞춰진다.

### 열 삭제

열이 시각적으로 정렬된 데이터에서 특정 열을 삭제할 때 유용하다:

```
name   age  city
Alice  30   Seoul
Bob    25   Busan
```

`age` 열을 삭제하려면:
1. 첫 번째 줄의 `a`(`age`의 시작)에 커서
2. `<C-v>` → `e` → `2j`로 블록 선택
3. `d`로 삭제

> **참고**: Visual Block은 화면상의 사각형 영역을 선택하므로, 열이 시각적으로 정렬되어 있어야 올바르게 동작한다. CSV처럼 필드 길이가 다른 데이터에는 적합하지 않다.

### 열 내용 교체

```
item1: old_value
item2: old_value
item3: old_value
```

`old_value`를 모두 `new_value`로 교체:
1. 첫 번째 `old_value`의 `o`에 커서
2. `<C-v>` → `2j` → `e`로 블록 선택
3. `c` → `new_value` 입력 → `<Esc>`

## Visual 모드의 유용한 기능

### gv - 이전 선택 영역 재선택

`gv`는 마지막으로 Visual 모드에서 선택했던 영역을 다시 선택한다. 들여쓰기 조절이나 반복 작업에 필수적이다.

### o - 선택 영역의 반대편으로

Visual 모드에서 `o`를 누르면 선택 영역의 시작점과 끝점을 오간다. 선택을 시작한 뒤 반대 방향으로도 확장해야 할 때 유용하다.

### 모드 전환

Visual 모드 안에서 다른 Visual 모드로 전환할 수 있다:
- `v` 상태에서 `V` → 줄 단위로 전환
- `V` 상태에서 `<C-v>` → 블록 선택으로 전환
- 같은 키를 다시 누르면 Visual 모드 해제

## Visual 모드 vs 오퍼레이터 + 모션

두 접근 방식을 비교해 보자:

| 작업 | Visual 모드 | 오퍼레이터 + 모션 |
|------|------------|-------------------|
| 단어 삭제 | `viwd` | `diw` |
| 괄호 안 변경 | `vi(c` | `ci(` |
| 3줄 복사 | `V2jy` | `3yy` |
| 줄 끝까지 삭제 | `v$d` | `d$` 또는 `D` |

오퍼레이터 + 모션이 더 짧고, `.`으로 반복하기 쉽다. 하지만 다음 상황에서는 Visual 모드가 더 유리하다:

- **정확한 범위를 확인**하고 싶을 때
- **블록 편집**이 필요할 때
- **비규칙적인 범위**를 선택해야 할 때
- 복잡한 선택 후 **명령을 결정**해야 할 때

## 실습: Visual 모드 연습

```javascript
const users = [
  { name: "Alice", age: 30, role: "admin" },
  { name: "Bob", age: 25, role: "user" },
  { name: "Charlie", age: 35, role: "user" },
  { name: "Diana", age: 28, role: "admin" },
];
```

1. `V`로 두 번째~네 번째 객체를 줄 단위 선택 → `>`로 들여쓰기
2. `<C-v>`로 `name` 앞의 공백을 블록 선택 → `d`로 삭제
3. `gv`로 다시 선택 → `>`로 원복
4. `<C-v>`로 모든 `"user"`를 블록 선택 → `c`로 `"viewer"`로 변경
5. `V`로 두 줄 선택 → `:sort`로 정렬

## 핵심 정리

- **`v`** (문자), **`V`** (줄), **`<C-v>`** (블록) 세 가지 Visual 모드
- 선택 후 **`d`**, **`c`**, **`y`**, **`>`**, **`<`**, **`=`** 등으로 조작
- **블록 선택 + `I`/`A`**: 여러 줄에 동시 삽입하는 강력한 기능
- **`gv`**: 이전 선택 재활성화
- **`o`**: 선택 영역의 반대편으로 이동
- 단순한 편집은 **오퍼레이터 + 모션**이 효율적, 복잡한 선택은 **Visual 모드**가 직관적
