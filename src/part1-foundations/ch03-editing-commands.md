# Chapter 3: 편집 명령의 조합

Chapter 1에서 Vim의 편집 언어(동사 + 명사)를, Chapter 2에서 다양한 모션(명사)을 배웠다. 이 챕터에서는 핵심 오퍼레이터(동사)를 깊이 파고들고, 실전에서 어떻게 조합하는지 익힌다.

## 핵심 오퍼레이터

### d - 삭제 (Delete)

`d`는 지정한 범위를 삭제하고 레지스터에 저장한다. "잘라내기(cut)"에 가깝다.

```
d{motion}    범위 삭제
dd           현재 줄 전체 삭제
D            커서부터 줄 끝까지 삭제 (d$와 동일)
```

실전 조합:

| 명령 | 동작 |
|------|------|
| `dw` | 커서부터 다음 단어 시작까지 삭제 |
| `diw` | 현재 단어 삭제 (inner word) |
| `daw` | 현재 단어 + 주변 공백 삭제 (a word) |
| `dd` | 현재 줄 삭제 |
| `3dd` | 현재 줄 포함 3줄 삭제 |
| `d$` 또는 `D` | 줄 끝까지 삭제 |
| `d0` | 줄 시작까지 삭제 |
| `dG` | 파일 끝까지 삭제 |
| `dgg` | 파일 시작까지 삭제 |
| `df;` | `;` 포함하여 삭제 |
| `dt;` | `;` 직전까지 삭제 |

### c - 변경 (Change)

`c`는 `d`와 동일하게 삭제하되, 즉시 Insert 모드로 전환된다. "삭제 후 입력"이다.

```
c{motion}    범위를 삭제하고 Insert 모드 진입
cc           현재 줄을 삭제하고 Insert 모드 진입
C            커서부터 줄 끝까지 삭제하고 Insert 모드 진입 (c$와 동일)
```

| 명령 | 동작 |
|------|------|
| `cw` | 단어 끝까지 변경 |
| `ciw` | 현재 단어 변경 |
| `ci"` | 따옴표 안의 내용 변경 |
| `ci(` | 괄호 안의 내용 변경 |
| `cc` | 현재 줄 내용 변경 (들여쓰기 유지) |
| `C` | 줄 끝까지 변경 |
| `ct;` | `;` 직전까지 변경 |

> **팁**: `d`와 `c`의 차이가 헷갈릴 때 — "삭제 후 바로 새 텍스트를 입력할 건가?" 그렇다면 `c`, 아니라면 `d`를 사용한다.

### y - 복사 (Yank)

Vim에서 복사를 "yank"라고 부른다. `y`는 지정한 범위를 레지스터에 복사한다.

```
y{motion}    범위 복사
yy           현재 줄 전체 복사
Y            현재 줄 전체 복사 (기본값, vim과 동일)
```

| 명령 | 동작 |
|------|------|
| `yiw` | 현재 단어 복사 |
| `yy` | 현재 줄 복사 |
| `3yy` | 현재 줄 포함 3줄 복사 |
| `y$` | 줄 끝까지 복사 |
| `yi"` | 따옴표 안의 내용 복사 |
| `yap` | 현재 단락 전체 복사 |

### p - 붙여넣기 (Put)

```
p     커서 뒤(또는 아래 줄)에 붙여넣기
P     커서 앞(또는 위 줄)에 붙여넣기
```

`p`와 `P`의 동작은 복사된 내용이 "줄 단위"인지 "문자 단위"인지에 따라 달라진다:

- **문자 단위** (`yiw` 등으로 복사): `p`는 커서 뒤에, `P`는 커서 앞에 삽입
- **줄 단위** (`yy` 등으로 복사): `p`는 아래 줄에, `P`는 위 줄에 삽입

## 반복의 힘: . (Dot Command)

`.`은 **마지막 변경(change)을 반복**한다. 단순해 보이지만 Vim에서 가장 강력한 명령 중 하나다.

### 실전 예시 1: 단어 변경

`foo`라는 변수를 모두 `bar`로 변경하고 싶다:

1. `/foo`로 첫 번째 `foo` 찾기
2. `ciw`로 단어 변경 → `bar` 입력 → `<Esc>`
3. `n`으로 다음 `foo`로 이동
4. `.`로 같은 변경 반복
5. `n` → `.` → `n` → `.` ... 반복

### 실전 예시 2: 줄 끝에 세미콜론 추가

여러 줄 끝에 `;`를 추가하고 싶다:

1. 첫 번째 줄에서 `A;`로 줄 끝에 `;` 추가 → `<Esc>`
2. `j`로 다음 줄로 이동
3. `.`으로 같은 동작 반복
4. `j.j.j.` ...

### 실전 예시 3: 들여쓰기 추가

여러 줄의 들여쓰기를 늘리고 싶다:

1. 첫 번째 줄에서 `>>`
2. `j.j.j.` ...

> **핵심**: `.`으로 반복할 수 있도록 편집 동작을 설계하는 것이 Vim 실력의 척도다.

### dot command가 반복하는 것

`.`이 반복하는 "변경"이란:
- Insert 모드에 진입하고 나올 때까지의 모든 입력 (`ciw` + 입력 + `<Esc>`)
- `d`, `c`, `y` 등의 오퍼레이터 + 모션 조합
- `x`, `r`, `J` 등의 단일 편집 명령
- `>>`, `<<` 등의 들여쓰기

`.`이 반복하지 **않는** 것:
- 모션 (이동만 한 것)
- 검색 (`/pattern`)
- Command-line 명령 (`:s/...`)

## Undo와 Redo

| 키 | 동작 |
|----|------|
| `u` | 실행 취소 (undo) |
| `<C-r>` | 다시 실행 (redo) |
| `U` | 현재 줄의 모든 변경 취소 (잘 안 쓰임) |

### Undo의 단위

Vim에서 undo의 단위는 "하나의 변경(change)"이다:
- Normal 모드에서의 명령 하나 (예: `dd`, `ciw` + 입력 + `<Esc>`)
- Insert 모드에 진입하고 나올 때까지가 하나의 변경

따라서 Insert 모드에서 긴 텍스트를 입력한 뒤 `<Esc>`, 그리고 `u`를 누르면 **입력한 모든 텍스트가 한 번에 취소**된다.

> **팁**: Insert 모드에서 중간에 undo 지점을 만들고 싶으면, `<C-g>u`를 누르면 된다. 이것을 `.`이나 `,` 입력 시 자동으로 추가하는 매핑을 설정하는 사람도 있다.

### Undo Tree

Vim의 undo는 단순한 선형 히스토리가 아니라 **트리 구조**다. 변경을 취소하고 새로운 변경을 하면 분기가 생긴다. 기본 `u`와 `<C-r>`로는 현재 브랜치만 탐색할 수 있지만, 나중에 배울 undotree 플러그인으로 전체 히스토리를 시각적으로 탐색할 수 있다.

## 추가 편집 명령

### 단일 문자 조작

| 키 | 동작 |
|----|------|
| `x` | 커서 아래 문자 삭제 (`dl`과 동일) |
| `X` | 커서 앞 문자 삭제 (`dh`와 동일) |
| `r{char}` | 커서 아래 문자를 `{char}`로 교체 (Normal 모드 유지) |
| `~` | 대소문자 토글 |

`r`은 `.`과 잘 어울린다. 한 문자를 교체한 뒤, 다른 위치로 이동해서 `.`으로 같은 교체를 반복할 수 있다.

### 줄 조작

| 키 | 동작 |
|----|------|
| `J` | 현재 줄과 다음 줄을 합침 (공백 추가) |
| `gJ` | 현재 줄과 다음 줄을 합침 (공백 없이) |
| `o` | 아래에 새 줄 추가 + Insert 모드 |
| `O` | 위에 새 줄 추가 + Insert 모드 |

### 들여쓰기

| 키 | 동작 |
|----|------|
| `>>` | 현재 줄 들여쓰기 |
| `<<` | 현재 줄 내어쓰기 |
| `>` + motion | 범위 들여쓰기 (예: `>ap`) |
| `=` + motion | 자동 정렬 (예: `=G`로 파일 전체 정렬) |

## 실전 편집 시나리오

### 시나리오 1: 함수 인자 변경

```javascript
// before
getUserData(userId, "admin", true);
// 두 번째 인자 "admin"을 "user"로 변경하고 싶다
```

1. `f"` → 첫 번째 `"` 로 이동
2. `ci"` → 따옴표 안의 내용 삭제 + Insert 모드
3. `user` 입력 → `<Esc>`

### 시나리오 2: 변수명 변경

```python
# before
result = calculate(data)
print(result)
return result
```

1. 첫 번째 `result` 위에 커서를 놓고
2. `ciw` → `output` 입력 → `<Esc>`
3. `n` (또는 `*`으로 먼저 검색한 후)
4. `.`으로 반복 → `n.n.`

### 시나리오 3: 여러 줄 삭제 후 새 코드 입력

```javascript
// 4~6번째 줄을 새 코드로 교체하고 싶다
```

1. 4번째 줄로 이동: `4G`
2. `3cc` → 3줄 삭제 + Insert 모드
3. 새 코드 입력 → `<Esc>`

## 실습: 편집 명령 연습

아래 텍스트를 파일로 만들고 연습해 보자:

```
const firstName = "John";
const lastName = "Doe";
const email = "john@example.com";
const age = 30;
const isActive = true;
```

연습 과제:
1. `firstName`을 `givenName`으로 변경 (`ciw`)
2. `"John"`을 `"Jane"`으로 변경 (`f"ci"`)
3. `email` 줄 전체 삭제 (`dd`)
4. `age` 줄과 `isActive` 줄의 순서 바꾸기 (`ddp`)
5. 모든 `const`를 `let`으로 변경 (`ciw` + `n.n.n.`)

## 핵심 정리

- **`d`** = 삭제 (레지스터에 저장), **`c`** = 삭제 + Insert 모드, **`y`** = 복사
- **`p`** / **`P`** 로 붙여넣기 (문자/줄 단위에 따라 동작이 다름)
- **`.`** (dot command)는 마지막 변경을 반복 — Vim에서 **가장 중요한 명령** 중 하나
- **`u`** 로 undo, **`<C-r>`** 로 redo
- `.`으로 반복 가능하도록 편집을 설계하는 습관을 들여라
- 단일 문자: `x`(삭제), `r`(교체), `~`(대소문자 토글)
- 줄 조합: `J`, 들여쓰기: `>>`, `<<`
