# Chapter 2: 모션과 내비게이션

Vim에서 커서 이동은 단순한 "이동"이 아니다. 모션(motion)은 Chapter 1에서 배운 동사(operator)와 조합되어 편집 범위를 결정하는 "명사" 역할을 한다. 따라서 모션을 잘 아는 것은 Vim 편집 능력의 근간이다.

## 기본 이동: h, j, k, l 그 너머

```
     k
     ↑
 h ←   → l
     ↓
     j
```

`h`, `j`, `k`, `l`은 Vim의 가장 기본적인 이동 키다. 화살표 키 대신 이것을 쓰는 이유는 홈 로우에서 손을 떼지 않기 위해서다.

하지만 **한 칸씩 이동하는 것은 비효율적이다.** `jjjjj`로 5줄을 내려가는 것은 Vim을 잘 사용하는 것이 아니다. 이 챕터에서 배울 더 효율적인 이동 방법들을 활용해야 한다.

> **팁**: `j`, `k`를 반복해서 누르고 있다면, 더 나은 이동 방법이 있다는 신호다.

## 단어 단위 이동

단어 단위 이동은 가장 자주 사용하는 모션 중 하나다.

| 키 | 동작 |
|----|------|
| `w` | 다음 단어의 **시작**으로 이동 |
| `b` | 이전 단어의 **시작**으로 이동 |
| `e` | 현재/다음 단어의 **끝**으로 이동 |
| `ge` | 이전 단어의 **끝**으로 이동 |

### 소문자 vs 대문자: WORD와 word

Vim은 "단어"를 두 가지로 구분한다:

- **word** (소문자 `w`, `b`, `e`): 알파벳, 숫자, `_`로 구성된 단어. 특수문자가 나오면 단어 경계로 인식
- **WORD** (대문자 `W`, `B`, `E`): 공백으로 구분되는 단어. 특수문자도 단어의 일부

예시 - `hello-world.txt` 위에서:

```
hello-world.txt
w →  w →  w → w    (word: 4번 이동 - hello, -, world, ., txt)
W →                 (WORD: 1번 이동 - 전체가 하나의 WORD)
```

코드에서 `function_name`은 `w`로 하나의 word지만, `object.method(arg)`는 여러 word다. 상황에 따라 `w`와 `W`를 적절히 사용하자.

## 줄 단위 이동

| 키 | 동작 |
|----|------|
| `0` | 줄의 **맨 처음** (0번째 열) |
| `^` | 줄의 첫 번째 **비공백 문자** |
| `$` | 줄의 **맨 끝** |
| `g_` | 줄의 마지막 **비공백 문자** |

`0`과 `^`의 차이:

```
    function hello()
↑   ↑
0   ^
```

들여쓰기가 있는 코드에서는 `^`가 더 유용하다.

### 줄 내 검색: f, t, F, T

특정 문자로 바로 이동하는 강력한 모션이다:

| 키 | 동작 |
|----|------|
| `f{char}` | 현재 줄에서 오른쪽으로 `{char}`를 찾아 **그 위**로 이동 |
| `F{char}` | 현재 줄에서 왼쪽으로 `{char}`를 찾아 **그 위**로 이동 |
| `t{char}` | 현재 줄에서 오른쪽으로 `{char}`를 찾아 **그 앞**으로 이동 |
| `T{char}` | 현재 줄에서 왼쪽으로 `{char}`를 찾아 **그 뒤**로 이동 |
| `;` | 마지막 f/t/F/T를 **같은 방향**으로 반복 |
| `,` | 마지막 f/t/F/T를 **반대 방향**으로 반복 |

예시:
```
const result = calculateTotal(items, discount);
```

커서가 맨 앞에 있을 때:
- `f=` → `=` 위로 이동
- `fc` → 첫 번째 `c` 위로 이동 (const의 c)
- `2fc` → 두 번째 `c` 위로 이동 (calculate의 c)
- `t(` → `(` 바로 앞으로 이동

> **핵심**: `f`와 `t`의 차이는 operator와 조합할 때 중요하다.
> - `df)` → `)` **포함**하여 삭제
> - `dt)` → `)` **직전**까지 삭제

## 화면 단위 이동

| 키 | 동작 |
|----|------|
| `<C-d>` | 반 화면 아래로 스크롤 |
| `<C-u>` | 반 화면 위로 스크롤 |
| `<C-f>` | 한 화면 아래로 스크롤 |
| `<C-b>` | 한 화면 위로 스크롤 |

### 화면 내 위치 이동

| 키 | 동작 |
|----|------|
| `H` | 화면의 **맨 위** (High) |
| `M` | 화면의 **중간** (Middle) |
| `L` | 화면의 **맨 아래** (Low) |

### 화면 조정

| 키 | 동작 |
|----|------|
| `zz` | 현재 줄을 화면 **중앙**으로 |
| `zt` | 현재 줄을 화면 **상단**으로 |
| `zb` | 현재 줄을 화면 **하단**으로 |

`<C-d>`로 이동한 후 `zz`로 화면을 정돈하는 패턴을 자주 사용한다.

## 파일 단위 이동

| 키 | 동작 |
|----|------|
| `gg` | 파일의 **맨 처음** |
| `G` | 파일의 **맨 끝** |
| `{number}G` | `{number}` 번째 줄로 이동 |
| `{number}gg` | `{number}` 번째 줄로 이동 (동일) |
| `%` | 매칭되는 괄호로 이동 `()`, `{}`, `[]` |

`:42`로도 42번째 줄로 이동할 수 있지만, `42G`나 `42gg`가 더 빠르다.

## 검색 기반 이동

| 키 | 동작 |
|----|------|
| `/pattern` | 아래 방향으로 `pattern` 검색 |
| `?pattern` | 위 방향으로 `pattern` 검색 |
| `n` | 같은 방향으로 다음 검색 결과 |
| `N` | 반대 방향으로 다음 검색 결과 |
| `*` | 커서 아래 단어를 아래 방향으로 검색 |
| `#` | 커서 아래 단어를 위 방향으로 검색 |

검색은 정규표현식을 지원한다. 기본적인 예:

```vim
/function          " 'function'이라는 텍스트 검색
/\vfunction\(      " 'function(' 검색 (\v는 very magic 모드)
/TODO\|FIXME       " 'TODO' 또는 'FIXME' 검색
```

> **팁**: 검색 후 `<C-l>`이나 `:noh`로 하이라이트를 끌 수 있다. 이것을 키맵에 등록해두면 편리하다.

## 모션과 오퍼레이터의 조합 실전

지금까지 배운 모션을 Chapter 1의 오퍼레이터와 조합해 보자:

| 명령 | 의미 |
|------|------|
| `dw` | 다음 단어 시작까지 삭제 |
| `d$` | 줄 끝까지 삭제 (`D`와 동일) |
| `d0` | 줄 시작까지 삭제 |
| `dG` | 파일 끝까지 삭제 |
| `dgg` | 파일 시작까지 삭제 |
| `df)` | `)` 포함하여 삭제 |
| `dt)` | `)` 직전까지 삭제 |
| `y$` | 줄 끝까지 복사 |
| `c/end` | "end"가 나올 때까지 변경 |
| `d/function` | "function"이 나올 때까지 삭제 |

## 줄 번호 활용

상대적 줄 번호(relative number)를 활성화하면 `j`, `k` 이동이 훨씬 편해진다:

```lua
-- init.lua에 추가
vim.opt.number = true
vim.opt.relativenumber = true
```

```
  3  function hello()
  2    const x = 1;
  1    const y = 2;
  7    return x + y;   ← 현재 커서 위치 (절대 줄 번호 7)
  1  }
  2
  3  function world()
```

현재 줄은 절대 번호, 나머지는 상대 번호가 표시된다. `3k`면 `hello()` 줄로, `3j`면 `world()` 줄로 이동한다.

## 실습: 모션 연습

다음 코드를 `nvim motion_practice.js`로 열고 연습해 보자:

```javascript
function calculateDiscount(price, discountRate) {
  if (discountRate < 0 || discountRate > 1) {
    throw new Error("Invalid discount rate");
  }
  const discountAmount = price * discountRate;
  const finalPrice = price - discountAmount;
  return Math.max(0, finalPrice);
}
```

1. `gg`로 맨 위로 → `w`를 반복해서 단어별 이동 확인
2. `$`로 줄 끝으로 → `0`으로 줄 시작으로
3. `f(`로 괄호로 이동 → `%`로 매칭 괄호로 이동
4. `/discount`로 검색 → `n`으로 다음 결과 탐색
5. `*`로 커서 아래 단어 검색
6. `3j`로 3줄 아래 이동 → `2k`로 2줄 위로

## 핵심 정리

- **`h`, `j`, `k`, `l`을 반복하지 마라** - 더 효율적인 모션을 사용하라
- **단어 단위**: `w`, `b`, `e` (word) / `W`, `B`, `E` (WORD)
- **줄 내 검색**: `f`, `t`는 줄 내에서 가장 빠른 이동 수단
- **화면 이동**: `<C-d>`, `<C-u>`로 스크롤, `H`, `M`, `L`로 화면 내 이동
- **검색**: `/`, `?`, `*`, `#`로 파일 전체에서 이동
- 모든 모션은 **오퍼레이터와 조합**하여 편집 범위를 지정할 수 있다
- **상대 줄 번호**를 활성화하면 세로 이동이 직관적이 된다
